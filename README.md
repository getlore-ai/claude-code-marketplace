# Lore — Claude Code Plugin Marketplace

Plugins for [Lore](https://getlore.ai), a research knowledge repository with semantic search and citations.

## Install

```
/plugin marketplace add getlore-ai/claude-code-marketplace
/plugin install lore@getlore
```

## What's included

- **lore** — MCP server with 9 tools for search, ingestion, research, and knowledge management. Includes a SKILL.md that teaches Claude when and how to use Lore's tools.
